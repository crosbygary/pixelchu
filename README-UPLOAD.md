# Publish Pixelchu on GitHub Pages

1. Unzip this archive on your computer. Do not upload the ZIP itself.
2. Create a public GitHub repository, for example pixelchu-pages.
3. Upload all extracted files and folders to its main branch. index.html
   must be at the repository root, with assets/ and downloads/ beside it.
   Include .nojekyll if your file browser shows hidden files.
4. Open Settings → Pages. Under Build and deployment, choose Deploy from
   a branch, select main and / (root), then Save.
5. Wait for deployment. Use the live URL shown in Settings → Pages.
   The usual form is https://YOUR-USERNAME.github.io/pixelchu-pages/

Privacy URL: append privacy.html to that live base URL.
Terms URL: append terms.html. Support URL: append contact.html.

No package install, build command, server, domain, or API key is needed.
All paths are relative. The site follows system light/dark mode.
Test the four ROM download links after publishing.
